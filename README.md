# Moneygement

## 概要
グループの金銭やり取りを管理するアプリ
最終的な全員の収支を計算してくれる

## 機能

### グループ作成
タイトル、更新日、作成者、部屋objectを管理
### 部屋object
部屋ID、メンバーリスト、金銭のやり取りリストを管理
### UI表示
- HomeScene: グループ選択、追加を管理する
アプリ起動時に最初に現れる画面
- ManagementScene: 
1. 金銭のやり取りを追加するScreen
だれが(複数選択可)払ったか、いくら払ったかを追加して最終的な計算を算出する
2. メンバーのリストを表示する。ホストはキックしたり部屋IDを確認したりできる
3. 今まで追加した金銭のやり取りを一覧にて表示できる。削除は支払者のみができる
また、現時点での全員の収支を確認できる
## 開発環境
- Unity 2022.x
- C#
