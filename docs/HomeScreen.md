# HomeScreenに関する設計

## GroupClass
グループ名を入力して作成ボタンを押すことで作成可能
- グループ名
- 更新日
- 作成者
- 部屋インスタンス
  をそれぞれ保持する

### メソッド
- AddGroup()

作成ボタンが押されたときに呼び出される

現状は仮のユーザーデータを持たせている。グループ名が空白の場合は何も返さない
- CreateGroupButton()

AddGroupから呼び出されて実際にView上にボタンを追加する

## PersonMangementClass
ユーザーデータに関するclass
- 名前
- アイコン
を保持する

このインスタンスがユーザー自体の情報となる
